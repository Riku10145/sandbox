# Third-party components and AI tool disclosure

## Third-party components

| Component | Source | How it was used | Included in this package |
|---|---|---|---|
| uliya-skill-kit 0.7.3 | UGREEN hackathon starter kit | Capability catalog 2.0.0 for feasibility checks, and the bundled static checker | No |

This package contains no open-source code, no libraries, no scripts and no binaries. It contains Markdown files only.

## AI tools

| Tool | Used for |
|---|---|
| Claude (Anthropic), through Claude Code | Reading the starter kit, checking feasibility against the capability catalog, and drafting the Skill files and the proposal. A person reviewed every file. |

At run time the Skill uses only the AI features that Uliya and its registered experts provide on the NAS. It does not call any external AI service.

## Credentials and personal data

The package contains no credentials, API keys or personal data. Folder names in the examples, such as `Shoots/2026-10-Test-Wedding`, are placeholders.
