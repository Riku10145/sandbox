# Project notes

## External assets and licenses

- Before using any external asset (texture, HDRI, 3D model, font, sound, image), open its license terms on the source site and read them. Check both the site-wide terms and the license shown on that asset's own page, since they can differ.
- Do not rely on remembered license facts. Verify them in the current session.
- Record every external asset in `ASSETS.md` next to the project that uses it, with the asset name, source URL, license, the date the terms were checked, and any attribution or usage conditions.
- If the terms cannot be reached or are unclear, do not use the asset. Tell the user and use a procedural or self-made alternative.
